About YatraIQ

Smart mobility through machine learning.

Our Project

YatraIQ is a machine learning based public transport journey time prediction system.

The system uses historical transport data, feature engineering and a trained machine learning model to estimate journey duration.

Technologies Used

Python | Flask | Machine Learning | HTML | CSS | JavaScript | Chart.js

Key Features

• Machine learning based journey prediction

• Dataset-based route selection

• Prediction history

• Interactive analytics dashboard

• Real-time frontend and backend integration
